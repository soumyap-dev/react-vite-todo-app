# 🤖 AI-Powered React Vite Todo App

A **smart and modern To-Do List** web application built using **React** and **Vite** with **advanced AI features** that solve real-world productivity problems.  
It helps users manage daily tasks efficiently with intelligent automation, smart suggestions, and productivity insights.

---

## 🧠 AI Features & Real-World Problem Solving

### 🎯 Smart Task Analysis
- **Automatic Categorization**: AI categorizes tasks into Work, Personal, Shopping, Learning, Home, and Financial
- **Priority Prediction**: Suggests HIGH/MEDIUM/LOW priority based on keyword analysis  
- **Duration Estimation**: Predicts task completion time (15 mins to 2+ hours)
- **Due Date Extraction**: Understands natural language like "tomorrow", "next week", "by Friday"

### 💡 Intelligent Suggestions
- **Real-time Smart Suggestions**: Context-aware recommendations as you type
- **Related Task Generation**: Suggests follow-up tasks (e.g., "Prepare agenda" for meetings)
- **Duplicate Detection**: Identifies and warns about similar existing tasks

### 📊 Productivity Analytics
- **Completion Rate Tracking**: Monitor your productivity with success percentages
- **Category-wise Analysis**: See performance across different task types
- **AI-Powered Insights**: Personalized recommendations to improve productivity
- **Pattern Recognition**: Identifies productivity trends and suggests improvements

### 🗣️ Natural Language Processing
- **Smart Input Processing**: Type naturally like "urgent meeting tomorrow with client"
- **Automatic Data Extraction**: Pulls out priority, category, duration, and due dates
- **Context Understanding**: Recognizes work vs personal tasks automatically

## 🚀 Getting Started

Follow these steps to run the AI-powered project locally:

```bash
# Clone the repository
git clone https://github.com/soumyap-dev/react-vite-todo-app.git

# Navigate into the project directory
cd react-vite-todo-app

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at [http://localhost:5173/]
